# Lisans metinleri

Projenin kendi lisansı kökteki [LICENSE](../LICENSE) dosyasında yer alır. Bu dizin üçüncü taraf bildirimlerini taşır; resmî sertifika veya ticari Qt lisansı sağlamaz.

| Bileşen | Yerel metin |
|---|---|
| Python | [Python-LICENSE.txt](Python-LICENSE.txt) |
| Noto Sans | [NotoSans-OFL.txt](NotoSans-OFL.txt) |
| NumPy ve paketindeki alt bileşenler | [NumPy lisans dizini](numpy-2.5.3/) |
| Pillow | [Pillow lisans dizini](pillow-12.3.0/) |
| Qt/PySide6/Shiboken açık kaynak metinleri | [LGPL 3](LGPL-3.0-only.txt), [GPL 3](GPL-3.0-only.txt), [GPL 2](GPL-2.0-only.txt) |
| PySide6 ve Shiboken dağıtım bildirimleri | [PySide6](pyside6_essentials-6.11.2/), [Shiboken](shiboken6-6.11.2/) |

Python, NumPy, Pillow ve Qt dağıtım bildirimleri mevcut çalışma ortamı paketlerinden; Noto Sans metni fontla birlikte gelen OFL dosyasından değiştirilmeden kopyalandı. GNU lisans metinleri [SPDX license-list-data](https://github.com/spdx/license-list-data/tree/main/text) kaynağından alındı. LGPL metni, atıf yaptığı GPL 3 metnini de içerir.

Qt paketlerindeki `LicenseRef-Qt-Commercial.txt` dosyasının bulunması ticari lisans satın alındığı anlamına gelmez. Kullanılacak açık kaynak koşulları ve bileşene özgü bildirimler ayrıca geçerlidir; [Qt lisans açıklaması](https://doc.qt.io/qt-6/licensing.html) ve [Qt for Python bildirimleri](https://doc.qt.io/qtforpython-6/licenses.html) referans alınmalıdır.

Bu dizin mevcut sürümlerin bildirimlerini saklar. Bağımlılık yükseltirken ilgili metinleri ve THIRD_PARTY.md listesini birlikte güncelle.
