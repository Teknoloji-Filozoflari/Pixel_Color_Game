# Piksel Atölyesi 0.16.1

900 hazır resimli, çevrim dışı piksel boyama oyunu için Linux paketleme güncellemesi.
Mevcut oyuncu ilerlemesi ve koleksiyon kimlikleri korunur.

## Bu sürüm

- AppImage ve DEB üretimi sabit Linux bağımlılıklarıyla güçlendirildi.
- Fedora 43 RPM, core24 strict Snap ve Nix/NixOS flake paketi eklendi.
- Temiz kurulum, sanal X11 pencere açılışı ve 900 resimlik koleksiyon kontrolleri eklendi.
- Kaynak ZIP, Python wheel/sdist ve SHA256SUMS aynı yayında sunulur.
- Ruff import sırası düzeltildi; oyun davranışı değiştirilmedi.

## Kurulum

```bash
# AppImage: x86_64, glibc 2.35+
chmod +x Piksel-Atolyesi-0.16.1-x86_64.AppImage
./Piksel-Atolyesi-0.16.1-x86_64.AppImage

# Debian 12/13 amd64
sudo apt install ./piksel-atolyesi_0.16.1-1_amd64.deb

# Fedora 43 x86_64
sudo dnf install ./piksel-atolyesi-0.16.1-1.fc43.x86_64.rpm

# snapd bulunan amd64 Linux; GitHub'dan yerel paket
sudo snap install --dangerous ./piksel-atolyesi_0.16.1_amd64.snap

# Nix / NixOS, flake desteğiyle
nix run github:Teknoloji-Filozoflari/Pixel_Color_Game/v0.16.1
```

FUSE yoksa AppImage `APPIMAGE_EXTRACT_AND_RUN=1` ile açılabilir.
AppImage sistemin EGL/OpenGL sürücü kitaplıklarını kullanır.
Snap Store, AUR ve resmî Nixpkgs yayını yapılmadı. Snap kayıtları normal
kurulumdan ayrı `~/snap/piksel-atolyesi/common` altında saklanır.

AppImage Ubuntu 22.04/24.04, DEB Debian 12/13, RPM Fedora 43 ve Snap Ubuntu
24.04/snapd ortamında test edilir. X11 kontrolleri Xvfb üzerinde yapılır.
Nix için x86_64 build, testler ve kurulu paketin offscreen açılışı doğrulanır;
ARM64 ve gerçek NixOS masaüstü doğrulanmamıştır.

Kurulum ve veri yolları: [Linux paketleme rehberi](https://github.com/Teknoloji-Filozoflari/Pixel_Color_Game/blob/v0.16.1/docs/LINUX_PACKAGES.md).
